# OpenClaude – Fork du leak Claude Code (Avril 2026)

## 🚀 Pourquoi c’est intéressant

Après le leak accidentel du code source de Claude Code (500 000 lignes) fin mars 2026, plusieurs forks ont émergé.

**OpenClaude** est actuellement le **meilleur fork** :
- Interface identique à Claude Code (CLI agentic ultra-puissant)
- Compatible avec **n’importe quel modèle** (pas bloqué chez Anthropic)
- Support local (Ollama) + cloud
- Toujours maintenu et actif en mai 2026

## Repo officiel
https://github.com/Gitlawb/openclaude

## Installation (recommandée)

```bash
# 1. Clone
https://github.com/Gitlawb/openclaude.git
cd openclaude

# 2. Installation
npm install
npm run build

# 3. Lancer
./bin/openclaude
```

## Commandes utiles

- `openclaude chat` → Mode chat normal
- `openclaude run [tâche]` → Mode agent autonome
- `openclaude --model gemini-2.5-pro` → Choisir un modèle
- `openclaude config` → Configuration
