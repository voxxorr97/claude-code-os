# ViralMysteryLipSync – Cold Cases & Histoires Non Résolues (Vidéos Prêtes à Poster)

## Objectif
Génère des Shorts 15-60s **entièrement montées** : 
- Hook puissant en 3s ("Ce que la police n’a JAMAIS dit...")
- Narration lip sync réaliste (avatar sombre ou real footage)
- B-roll creepy (images d’archives, reconstitutions AI, ambiance nuit)
- Texte à l’écran + sous-titres dynamiques
- Musique trending tension (libre de droits)
- Score viral estimé + CTA ("Part 2 en com ?")

## Outils open source prioritaires (Termux-friendly)
- **MuseTalk + LivePortrait** → lip sync ultra-réaliste 2026
- **MoneyPrinterV2** (GitHub FujiwaraChoki) → pipeline complet script → vidéo finie
- MoviePy + FFmpeg pour montage auto
- Stock libre + générateur d’images AI pour B-roll

## Workflow Agentic (avec SelfEvolve + Hermes loop)
1. /mystery-gen [affaire ou "cold case France 2020s"] → script viral + structure prouvée
2. Génère voix + lip sync
3. Montage auto + effets suspense
4. Output MP4 prêt + thumbnail idée + score viral (1-10)
5. /evolve-mystery → analyse performance (vues/impressions) → améliore prochaine vidéo

## Structure Viral Prouvée (copie-colle ce template)
- 0-3s : Hook choc ("L’affaire qui hante encore les flics...")
- 3-20s : Faits + twist mystérieux
- 20-45s : Théories / ce qui manque
- Fin : CTA fort ("Tu penses quoi ? Commente") + cliffhanger

## Commandes
/mystery-gen "Disparition de X à Y" → vidéo complète
/viral-score [script] → optimise pour max rétention

Twist revenue : séries multi-parties (Part 1, 2, 3) → rétention folle + monétisation longue traîne.
