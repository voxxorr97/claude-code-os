# Token Efficiency Codex v1

## Objectif
Maximiser l’efficacité token avec Codex (GPT-5.5) tout en gardant une haute qualité de sortie.

## Règles d’or pour Codex
1. Instructions très claires et structurées (Codex adore ça)
2. Demander des réponses courtes et actionnables
3. Utiliser des checkpoints réguliers
4. Éviter les répétitions inutiles
5. Utiliser le format JSON quand possible pour les tâches complexes
6. Demander un “rapport de progression” au lieu de tout renvoyer

## Prompt Template Optimisé Codex
```
[CONTEXTE]
[OBJECTIF CLAIR]
[CONTRAINTES]
[FORMAT DE SORTIE ATTENDU]
[CHECKPOINT]
```

## Astuces Spécifiques Codex
- Codex est plus économe que Claude en output
- Il réagit très bien aux instructions numérotées
- Utilise “Step by step” + “Report only the result”
- Pour les tâches longues : demander des mises à jour toutes les 30-60 min
