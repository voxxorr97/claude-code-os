# ViralLipSyncPipeline – Vidéos Montées Prêtes à Poster (Revenue Passif)

## Objectif
Génère des vidéos courtes (15-60s) **entièrement montées** : hook puissant + B-roll + texte dynamique + musique trending + lip sync parfait. Score viral intégré (curiosité gap, pattern interrupt, CTA fort).

## Outils open source prioritaires (zéro ou très faible coût)
- **MuseTalk** ou **LivePortrait** → meilleur lip sync réaliste 2026 (réel footage ou avatar)
- **MoviePy + FFmpeg** (Termux installable) → montage auto (cuts, zooms, transitions)
- **CapCut API / auto-export** ou script Python pour effets viraux
- Alternative full pipeline : MoneyPrinterV2 (GitHub open source) – tape topic → vidéo finie

## Workflow Agentic (Self-Evolve activé)
1. /viral-gen [niche + idée] → script avec viral score + structure
2. Génère audio (voix naturelle)
3. Lip sync sur avatar ou real face (MuseTalk)
4. Ajoute B-roll auto (stock libre + AI gen)
5. Montage dynamique + sous-titres + musique trending
6. Output MP4 prêt → score viral estimé (1-10)

## Commandes
/viral-lipsync [niche ex: "fitness motivation femme 35+"] → pipeline complet
/evolve-video → analyse dernière vidéo + améliore prochaine (Hermes style)

## Twist Revenue
Priorise niches passives : faceless motivation, tips ecom, product stories, ASMR facts. Vidéos optimisées pour TikTok/YouTube Shorts/Instagram.

Compatible Termux : scripts bash légers. Combine avec ecom-revenue-agent pour funnel direct.
