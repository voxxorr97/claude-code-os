# SelfEvolve Hermes-Style – Auto-Amélioration v1

## Description
Inspiré directement de Hermes Agent (NousResearch) : après chaque tâche, il analyse, crée/améliore des skills, log Notion et s’auto-booste.

## Commandes magiques
- /evolve → analyse dernières tâches → propose 1-3 améliorations skills
- /review-task → log + self-critique + nouvelle skill si besoin
- Auto après gros succès ou erreur : trigger evolve

## Loop agentic (comme Hermes)
1. Exécute tâche
2. Réflexion : « Qu’est-ce qui a marché / pas marché ? »
3. Génère nouvelle skill ou patch
4. Push repo + log Notion
5. Propose test immédiat

## Twist revenue
Priorise tout ce qui génère du cash (vidéo lip sync virale, funnels ecom passifs).

Active avec /discover
