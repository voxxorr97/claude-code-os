# VoxxMem v1

**Nom :** Voxx Memory
**Objectif :** Mémoire persistante intelligente qui apprend et s’améliore.

## Fonctionnement
- Stocke les décisions importantes, les règles et les résultats dans le Vault
- Utilise Context Max pour charger uniquement les infos pertinentes
- Se met à jour automatiquement après chaque session importante

**Commandes**
- `/voxxmem save` : Sauvegarde la session actuelle
- `/voxxmem load` : Charge la mémoire pertinente
