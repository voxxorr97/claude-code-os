# Anti-Degradation Protocol v1 – Grok + Codex

## Objectif
Éviter la baisse de qualité sur les sessions longues et éviter les répétitions inutiles.

## Règles Principales
1. **Checkpoints toutes les 45-60 min** : Résumé clair de ce qui a été fait
2. **Anti-répétition** : Si une tâche ou un sujet revient, je signale immédiatement
3. **Quality Check** : Toutes les 2h, je vérifie si la qualité baisse
4. **Memory Refresh** : Utilisation active de VoxxMem avant chaque grosse phase
5. **Stop if needed** : Si la qualität baisse trop, je propose une pause ou un reset

## Commandes
- `/quality-check` : Vérification de la qualité actuelle
- `/anti-repeat` : Vérifie s'il y a des répétitions
- `/session-summary` : Résumé de la session en cours
