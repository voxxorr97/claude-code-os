# VideoGen Lite v1

**Nom :** VideoGen Lite
**Objectif :** Pipeline vidéo complet avec Grok (images) + outils gratuits.

## Règle d’or
Toutes les histoires doivent être basées sur des **faits réels, documentés ou déclassifiés**.

## Pipeline
1. Recherche cold case réel
2. Storyboard + images avec Grok
3. Prompt vidéo optimisé (Kling / Luma / Pika)
4. Log dans le Vault

**Commandes**
- `/videogen [nom cold case]` : Lance le pipeline complet
