# Memory Ingestion Protocol v1

**Objectif :** Standardiser la création d’entrées Vault de haute qualité.

## Structure obligatoire
1. Titre clair + métadonnées
2. Résumé (max 5 lignes)
3. Points clés / Décisions
4. Fil conducteur
5. Instructions à suivre
6. Prochaines actions
7. Tags

**Commande :** `vault entry` ou `vault entry follow protocol`
