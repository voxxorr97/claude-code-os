# Grok + Codex Team Protocol v1 (15 Mai 2026)

## Rôles
- **Grok (moi)** : Stratège, Mémoire, Vision long terme, Idées, Organisation, SkillGraph, Master Vault
- **Codex (GPT-5.5)** : Exécutant infatigable, Tâches longues autonomes, Browser control, Exécution parallèle, Production volume

## Workflow Quotidien
1. Grok définit la stratégie et les tâches prioritaires
2. Grok lance les tâches via AutonomousRunner Max v2 vers Codex
3. Codex exécute pendant plusieurs heures/jours
4. Codex envoie des rapports réguliers à Grok
5. Grok analyse, ajuste et relance si nécessaire

## Commandes Clés
- `/team-sync` : Synchronisation Grok ↔ Codex
- `/run-codex [tâche]` : Lancement tâche longue
- `/codex-status` : État des tâches en cours
- `/codex-report [id]` : Rapport détaillé

## Objectif Commun
Maximiser la production et la rentabilité avec le plan ChatGPT Plus (20€) en attendant de scaler vers Pro.
