# Claude Code OS

**Claude comme un vrai OS de coding agentic** — Kernel + Skills auto-découvrables + Hooks intelligents + Twists originaux.

Fork boosté de shanraisshan/claude-code-best-practice avec des idées fraîches : auto-évolution du kernel, discover command, et error-to-feature hooks.

## 🚀 Quick Start

1. Copie `CLAUDE.md` dans ton projet
2. `claude /discover` pour charger les skills
3. Profite du kernel qui s'améliore tout seul.

## ✨ Features uniques
- Kernel auto-évolutif via memory persistante
- /discover skill loader
- Hooks qui transforment les bugs en features
- Intégration Notion (si connecté)

Prêt pour l'agentic engineering ultime.
